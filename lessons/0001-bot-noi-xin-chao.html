Bot của bạn nói “Xin chào”

Dựng dự án Python bằng uv, đọc script đầu tiên qua lăng kính JS, và gửi tin nhắn Telegram từ code.

Chiến thắng của bài này: điện thoại của bạn rung lên với tin nhắn “Xin chào từ Python 🐍” do chính script Python của bạn gửi. Khoảng 30–40 phút.

Bạn đã biết lập trình, nên bài này không dạy lại biến hay hàm. Nó chỉ làm ba việc: chỉ cho bạn “npm của Python”, chỉ ra những chỗ Python khác JS trong một script thật, và nối script đó với Telegram, bước đầu tiên của bot nhắc việc bạn sẽ xây: mọi lời nhắc sau này đều là một lần gọi sendMessage như thế này.

2. Đọc script: sáu chỗ khác JS

Đây là toàn bộ script bạn sẽ chạy. Đọc lướt trước, rồi xem bảng bên dưới.

import os

import httpx
from dotenv import load_dotenv

load_dotenv()  # đọc file .env vào os.environ (giống process.env)
TOKEN = os.environ["TELEGRAM_TOKEN"]
API = f"https://api.telegram.org/bot{TOKEN}"


def call(method: str, **params) -> dict:
    """Gọi một method của Bot API, trả về phần `result`."""
    r = httpx.post(f"{API}/{method}", json=params)
    data = r.json()
    if not data["ok"]:
        raise RuntimeError(data["description"])
    return data["result"]


def main():
    me = call("getMe")
    print(f"Bot của bạn: @{me['username']}")

    updates = call("getUpdates")
    if not updates:
        print("Chưa có tin nhắn nào. Mở Telegram, nhắn /start cho bot, rồi chạy lại.")
        return

    chat_id = updates[-1]["message"]["chat"]["id"]
    call("sendMessage", chat_id=chat_id, text="Xin chào từ Python 🐍")
    print(f"Đã gửi tin nhắn tới chat {chat_id}")


if __name__ == "__main__":
    main()

Hai thứ còn lại: method: str và -> dict là type hint, kiểu TypeScript nhưng Python không kiểm tra lúc chạy. Còn if __name__ == "__main__": tương đương require.main === module: chỉ chạy main() khi file được chạy trực tiếp, không chạy khi bị import.

Bot API đơn giản chỉ là HTTP: https://api.telegram.org/bot<token>/TÊN_METHOD, trả về JSON có ok và result (Bot API docs). Hàm call ở trên chỉ bọc đúng quy ước đó.

3. Làm: gửi tin nhắn đầu tiên

  1. Tạo bot. Trong Telegram, mở @BotFather, gửi /newbot, đặt tên và username (phải kết thúc bằng bot). BotFather trả về một token. Telegram dặn: “treat it like a password” (Telegram tutorial). Đừng dán token vào chat với tôi.
  2. Tạo dự án trong thư mục bot/ của repo python-todo-bot: 
    cd ~/Documents/Training/python-todo-bot
uv init bot --app --no-package --python 3.14
cd bot
uv add httpx python-dotenv
    httpx đóng vai trò của fetch/axios (HTTPX quickstart). python-dotenv giống gói dotenv của Node.
  3. Cất token vào file bot/.env. File .gitignore của repo đã chặn .env, nhưng hãy chạy git status để chắc nó không hiện ra. Repo là public: 
    TELEGRAM_TOKEN=dán-token-của-bạn-vào-đây
  4. Viết code. Thay toàn bộ nội dung main.py bằng script ở mục 2 (nút copy ở góc khối code). Hãy thử gõ lại bằng tay ít nhất hàm call: ngón tay nhớ thụt lề nhanh hơn mắt.
  5. Chạy lần 1: uv run main.py. Bạn sẽ thấy tên bot và lời nhắc “Chưa có tin nhắn nào”. Nếu thấy Unauthorized, token trong .env bị sai.
  6. Nhắn /start cho bot của bạn trên Telegram, rồi chạy lại uv run main.py. Kiểm tra điện thoại. 🎉
Vì sao phải nhắn bot trước? (tự đoán trước khi mở)

Bot không được phép nhắn trước cho người chưa từng nhắn nó. Và getUpdates chỉ trả về tin nhắn mà bot đã nhận, nên đó là cách bot biết chat_id của bạn. Sau này, để nhắc việc đúng giờ, bot sẽ lưu chat_id của bạn cùng với mỗi task và gửi bất cứ lúc nào.

4. Nhớ lại (đừng cuộn lên)

1. Lệnh uv tương đương npm install httpx là gì?

uv add vừa ghi vào pyproject.toml vừa cài vào .venv và cập nhật uv.lock.

2. Python dùng gì để biết dòng nào thuộc thân hàm?

Thụt lề là cú pháp. Trộn tab với dấu cách hoặc lệch một dấu cách đều gây IndentationError.

3. me = call("getMe") trả về một dict. Lấy username thế nào?

Dict dùng ngoặc vuông. me.username sẽ báo AttributeError.

4. Với h = 8 và m = 5, f"{h:02}:{m:02}" in ra gì?

:02 là format spec: rộng 2 ký tự, thêm số 0 bên trái. Bạn sẽ cần nó để in giờ nhắc ở thử thách bên dưới.

5. Khối if __name__ == "__main__": có tác dụng gì?

Giống require.main === module. Nó giúp sau này bạn import call từ file khác mà không vô tình gửi tin nhắn.

6. Trong call("sendMessage", chat_id=1, text="hi"), biến params là kiểu gì?

**params gom keyword arguments thành {'chat_id': 1, 'text': 'hi'}, nên truyền thẳng vào json= được. (*args với một dấu sao mới là tuple.)

5. Thử thách: gửi danh sách việc

Sửa main() để bot gửi danh sách task hôm nay thay vì “Xin chào”. Đây là bản nháp của lệnh /list sau này. Bắt đầu với dữ liệu này:

tasks = [
    {"text": "Uống thuốc", "hour": 8, "minute": 0, "repeat": "hằng ngày"},
    {"text": "Gọi điện cho mẹ", "hour": 19, "minute": 30, "repeat": None},
    {"text": "Tập thể dục", "hour": 6, "minute": 5, "repeat": "T2, T4, T6"},
]

Tin nhắn mong muốn, mỗi task một dòng:

⏰ 08:00 Uống thuốc (🔁 hằng ngày)
⏰ 19:30 Gọi điện cho mẹ (một lần)
⏰ 06:05 Tập thể dục (🔁 T2, T4, T6)
Gợi ý 1: vòng lặp và nối chuỗi

for t in tasks: giống for (const t of tasks). Gom các dòng vào một list bằng lines.append(...) (giống push), rồi nối: "\n".join(lines). Để ý thứ tự đảo ngược so với JS lines.join("\n").

Gợi ý 2: “🔁 hằng ngày” hay “một lần”

None là null của Python và là falsy. Toán tử ba ngôi đọc như câu nói: a if điều_kiện else b. Bên trong f-string, dùng nháy đơn cho key: f"{t['text']}".

Lời giải (chỉ mở sau khi đã chạy thử) 
lines = []
for t in tasks:
    repeat = f"🔁 {t['repeat']}" if t["repeat"] else "một lần"
    lines.append(f"⏰ {t['hour']:02}:{t['minute']:02} {t['text']} ({repeat})")

call("sendMessage", chat_id=chat_id, text="\n".join(lines))

Khi làm xong, báo cho tôi. Tôi sẽ ghi nhận vào hồ sơ học tập, và bài sau sẽ biến script “chạy một lần” này thành bot luôn lắng nghe, nhận lệnh /add. Nhớ commit code trong bot/ (trừ .env) và push lên repo.
