Python & công cụ

uv
Công cụ quản lý phiên bản Python, môi trường ảo và thư viện. Tương đương nvm + npm.
virtual environment (.venv)
Thư mục chứa Python và thư viện riêng của một dự án. Tương đương node_modules.
dependency
Thư viện bên ngoài mà dự án cần, khai báo trong pyproject.toml.
module
Một file .py, có thể import được.
dict
Kiểu ánh xạ key → value, tương đương object/Map trong JS. JSON được parse thành dict.
list
Dãy có thứ tự, thay đổi được, tương đương array.
f-string
Chuỗi có tiền tố f, nhúng biểu thức trong {}. Tương đương template literal.
keyword argument
Tham số truyền theo tên: f(text="hi"). **kwargs gom chúng thành dict.
type hint
Chú thích kiểu như x: str, -> dict. Không được kiểm tra lúc chạy.

Telegram

BotFather
Bot chính thức của Telegram dùng để tạo và quản lý bot.
token
Chuỗi bí mật xác thực bot với Bot API. Giữ như mật khẩu, để trong .env.
method
Một thao tác của Bot API, ví dụ sendMessage, gọi bằng HTTP tới …/bot<token>/<method>.
update
Một sự kiện bot nhận được, ví dụ tin nhắn mới.
chat_id
Số định danh cuộc trò chuyện. Bot cần nó để gửi tin nhắn tới đúng người.
long polling
Cách lấy update: bot hỏi Telegram “có gì mới không?” và chờ. Đây là cách getUpdates hoạt động.
